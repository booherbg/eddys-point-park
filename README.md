# Eddy's Point Park

A park builder inspired by RollerCoaster Tycoon, made for an 8 year old to fall in love
with: original pixel art and music, in the browser. An early build.

**Play:** https://blainebooher.com/eddys-point-park/

Click the page once for sound. Your parks save in your browser.

This repository holds only the built game (version 0.5.1688, build c6288905).
